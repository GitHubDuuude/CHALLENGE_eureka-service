# muCARD - Eureka Server

API Gateway central del proyecto **muCARD**, una plataforma multijugador de juegos de cartas.  
Este servicio actúa como punto único de entrada para las solicitudes del cliente y las enruta hacia los microservicios registrados en **Eureka Server**.
